# 利用手順書

[README](../README.md) · [推奨設定](recommended-settings.md) · [技術解説](technical-guide.md)

## 対象版

QGIS 3.44.x向けです。配布済みのQGIS公式版 **0.12.2（実験的プラグイン）** とGitHub Release **v0.12.4** の標準処理を説明します。開発中のmainにも基本手順を適用できますが、版番号が同じ0.12.4でも配布ZIPと機能は同一ではありません。mainの「欠測・端部の処理方式」は「標準」のまま使います。画面内の手順書リンクとPSS近似方式は開発版の機能で、既存の配布ZIPには含まれません。

版はプラグイン管理画面・処理画面の説明先頭・実行ログで確認します。QGIS 4は対象外です。

## 1. 導入・起動

1. QGISの「プラグイン」→「プラグインの管理とインストール」で実験的プラグインの表示を有効にし、CS Map Sheetsを検索します。版が0.12.2か確認してインストール・有効化します。
2. ZIPで導入する場合は[Release v0.12.2](https://github.com/yo-1/csmap-sheets/releases/tag/v0.12.2)の登録用 `csmap_sheets-v0.12.2.zip` を取得し、「ZIPからインストール」で指定します。GitHubの「Source code」ZIPは登録用ZIPではありません。
3. GitHub版0.12.4を使う場合は[Release v0.12.4](https://github.com/yo-1/csmap-sheets/releases/tag/v0.12.4)の登録用ZIPを使います。QGIS公式0.12.2と配布経路・版を混同しないでください。
4. 「ラスタ」→「CS Map Sheets」→「CS立体図・国土基本図図郭出力」、ツールバーのアイコン、またはプロセッシングツールボックスから開きます。処理名は「DEMマージ・CS色調調整・国土基本図図郭・XYZ出力」です。

NumPy・GDALはQGISのPython環境に必要です。SciPyは任意です。LAS/LAZ・不規則テキスト点の前処理には外部PDAL 2.9以降が必要ですが、下記GeoTIFF手順には不要です。

## 2. 小範囲のDEMを用意

初回は座標系・標高単位・鉛直基準・NoDataが分かるローカルの**単バンド標高GeoTIFFを1〜2枚**用意します。RGBの地図画像や陰影画像からは作れません。提供元の仕様で標高がm単位か、同じ鉛直基準かを確認します。本プラグインは鉛直基準の変換を行いません。

標高VRT（`.vrt`）も入力できます。参照先が存在する単バンド標高で、CRS・NoDataが定義されているか、必要な上書きを指定できることが条件です。VRTだけを移動せず、参照先も保管してください。

他形式は[入力ガイド](../csmap_sheets/INPUT_GUIDE_ja.md)で列・単位・付属ファイルを確認してください。LEMには同名CSV/TXTメタデータ、TIFFには必要に応じてTFWと明示的な水平座標系が必要です。

## 3. 基本のCS立体図を作る

この例は**画面の既定の独自方式を使う試行手順**です。全国共通の最適設定や納品仕様ではありません。

1. 【設定】設定プロファイルを「画面の設定を使用」のままにします。
2. 【入力】入力形式を「標高ラスタ（GeoTIFF・IMG・ASC）」にし、「入力ファイル」にDEMを指定します。QGIS読込み済みなら「読込み済み標高ラスタ」も使えます。同じDEMを複数の方法で重ねて指定しないようにします。
3. 多数の入力は専用フォルダーへまとめ、「入力ファイル」を空にして「入力フォルダー」を使います。個別選択は30件までです。サブフォルダー検索は既定で有効です。明示ファイルがあると入力フォルダーは使用されません。
4. 「標高ラスタの座標系・解像度・格子をそろえる」は有効のままにします。GeoTIFFの入力セル間隔・CRSはファイルから読みます。**【テキスト】入力格子間隔はGeoTIFFには使いません。**
5. 【出力・図郭】対象地区・測地系に合う「出力の平面直角座標系」を選びます。EPSG:6677（JGD2011第IX系）は例で、全国共通ではありません。空欄なら入力から推定を試みますが、経緯度GeoTIFF等で推定できなければ明示指定が必要です。採用CRSをログでも確認します。
6. 図郭レベルは既定5000、出力セルサイズは入力DEMに合う値にします。1m DEMなら試行値1mです。5m DEMを1mへ補間しても観測精度は上がりません。
7. 【地形計算】開発版で「欠測・端部の処理方式」がある場合は「標準」のままにします。平滑化は「地上距離（m）」・3m、傾斜法はHorn法とします。【配色】は「独自方式 v0.4互換」・「従来標準」です。この組合せの実効曲率範囲は±0.05 1/m、標高色範囲は0〜3000mです。表示欄と実効値の違いは[推奨設定](recommended-settings.md)を参照してください。
8. 初回のGeoTIFF確認だけなら【XYZ】「XYZタイルも生成する」を**オフ**にします（実装の既定はオン）。【出力】全域を結合したGeoTIFF・終了後の読込みはオンのままにします。
9. 入力仕様を確認してから「全入力の標高がm単位で、鉛直基準が統一済みであることを確認した」をチェックします。単位変換のスイッチではありません。
10. 「出力先の親フォルダー」に書込み可能で空き容量のある場所を指定し、「実行」を押します。

ライブプレビューはありません。設定変更後は小範囲で再実行して比較します。ツールバー等から開いた画面では、誤操作防止のため数値をホイールで変更できません。クリック・キー入力を使います。

## 4. 完了と成果の確認

毎回 `csmap_日時_識別子` が新規作成されます。`run.json` の `status` が `completed` か確認します。キャンセル・失敗時の残存ファイルは部分成果です。

| 成果 | 内容・確認 |
|---|---|
| `cs_relief.vrt` | 図郭群をまとめた表示用参照。既定でQGISへ追加 |
| `cs_relief_merged.tif` | 結合GeoTIFFを有効にした場合の単独画像 |
| `sheets/図郭番号.tif`・`.tfw` | 図郭別RGBA画像とワールドファイル |
| `sheet_index.gpkg` | 出力図郭の範囲 |
| `run.json` | 入力順・採用設定・ライブラリ版・処理結果 |
| `xyz/` | XYZを有効にした場合のタイル |

元DEM・既知の地物と重ねて位置・範囲・谷尾根・欠測・異常段差を確認します。RGB画像から標高を復元する成果ではなく、地形判読は元DEM等と併せて行います。

VRTは他ファイルを参照します。成果フォルダーや元入力・変換成果の移動・削除で参照切れになる場合があります。単独で渡す画像は結合GeoTIFF等を使い、元データ・設定・ログも別途保管してください。

**0.12.3以降（GitHub版0.12.4を含む）：** `sheet_index.qml` で索引を塗りなし・枠線で表示します。GPKGとQMLは一緒に保管します。0.12.2で索引が画像を覆う場合は、QGISのシンボロジで塗りをなくすか索引を非表示にします。

## 5. 設定JSONの再利用

高度なパラメータを展開し、「現在の処理設定をJSONへ保存」に保存先を指定して実行します。保存は処理準備時なので、JSONの存在は画像の完了を意味しません。次回は「外部JSONプロファイル」と「読込む設定プロファイル（JSON）」を指定します。

入力・入力形式・出力先・出力CRS・標高単位確認は保存対象外なので毎回確認します。読込みは実行時に適用され、画面の全欄を保存値へ書き戻す機能ではありません。採用値はログと `run.json` で確認します。

**0.12.3以降（GitHub版0.12.4を含む）：** 拡張子補完と最終パスの上書き確認を改善しています。0.12.2ではこの改善を前提にせず、`.json` を含む別名を明示してください。

GitHub版0.12.4では「マージ・格子整合済みの標高DEMをGeoTIFFでも保存する」をオンにすると、平滑化前の単バンド標高を `dem_merged.tif` へ保存できます（既定オフ）。色付きCS画像とは別です。この設定を含むJSONは未対応旧版では拒否されます。詳細は[0.12.4の記録](validation/merged-dem-0.12.4.md)を参照してください。

## 6. XYZが必要な場合

生成をオンにし、初回は小範囲・ズーム12〜14程度で確認します（暫定推奨。実装既定は12〜16）。PNGが既定です。WebPはWEBPドライバが必要で、選択時の既定は非可逆QUALITY 75です。画素値保持にはPNGまたはWebP可逆を選びます。

XYZはEPSG:3857・256px・`z/x/y.png` または `.webp` で、国土基本図の分割とは異なります。ズームを1増やすと広域では候補数がおよそ4倍になるため、上限エラー時は範囲・ズームを見直します。Webサーバー公開は別作業です。詳細は[詳細README](../csmap_sheets/README_ja.md)を参照してください。

## 困ったとき

| 状況 | 確認 |
|---|---|
| プラグインが見つからない | 実験的プラグインの表示・QGIS版・導入版 |
| 出力CRSを推定できない | 提供元の測地系・系番号を確認し明示。第IX系を無条件に選ばない |
| 座標がずれる | 入力CRS、測量X/YとGIS X/Yの順序、TFW・メタデータ |
| 全透明・欠測周囲が広い | NoData定義、入力範囲、σ、周辺DEM |
| 暗い・色が飽和 | プロファイルの実効範囲を確認、小範囲で配色を比較 |
| 大量入力で停止 | 個別選択を専用フォルダーへ変更、入力一覧・空き容量・ログ |
| WEBP不足 | PNGを明示選択するか対応環境を用意。自動切替はしない |
| 中断後に成果が残る | 部分成果。次回は新しい実行として処理。途中再開は未対応 |

報告には版、OS、QGIS/GDAL、入力形式・CRS・格子、設定JSON、ログ、再現手順を添えます。公開Issueへ非公開データ・秘密情報を添付しないでください。
