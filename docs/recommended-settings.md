# 推奨設定

[利用手順書](user-guide.md) · [技術解説](technical-guide.md) · [README](../README.md)

## 対象・確からしさ

v0.13.0（GitHub Release・QGIS公式通常版掲載を確認済み）、QGIS 3.44.xを対象とします。欠測・端部の方式選択とプロファイルv5を含み、既定は従来のsafe_maskです。通常版指定とWindows実機合格は別に確認します。PR #57の上限警告は含みません。

- **実装上の既定値**：コードが採用する値。最適性の証明ではありません。
- **暫定推奨**：試行の出発点。対象地形・入力品質・判読目的で再評価します。
- **比較検証済み**：比較対象・条件・指標・証跡を特定できる結果だけを指します。計算回帰試験の成功と地形判読上の優位性は別です。

全国・全DEMに共通する「比較検証済みの最適設定」はありません。実DEMのFME/MIERUNE比較、FME/PSS参照実出力比較、広域負荷は[監査記録](validation/project-audit-20261017.md)で残作業です。本版の境界補完方式は明示選択の近似で、暫定推奨の標準処理には使いません。

v0.13.1は空図郭スキップ修正を含み、GitHub Release公開済みです。QGIS公式の申請・承認・配信は別途確認します。既存の操作・設定プロファイルv5を維持します。公開・検証の状態は[版別記録](validation/release-0.13.1.md)を参照してください。

## 実装上の既定値

根拠：[algorithm.py](../csmap_sheets/algorithm.py)の `initAlgorithm`・`prepareAlgorithm`、[pipeline.py](../csmap_sheets/engine/pipeline.py)の `validate_config`。

| 設定 | 画面初期値 | 適用条件 |
|---|---|---|
| プロファイル | 画面の設定を使用 | 組込み・外部JSONで対象設定を上書き |
| 描画・独自色 | 独自方式 v0.4互換・従来標準 | 曲率±0.05 1/m、標高0〜3000m、自動標高範囲オフを適用 |
| セル・図郭 | 1m・5000 | 再投影後の格子・図郭寸法。DEM精度保証ではない |
| 曲率平滑化 | m方式3m | px欄の3pxはpx方式選択時だけ使用 |
| 傾斜法 | Horn | 未平滑化標高の3×3加重差分。中央差分は従来互換 |
| 欠測・端部（0.13.0） | 標準（`safe_mask`） | 境界補完は明示選択時のみ。配布済みv0.12.4には選択欄なし |
| 曲率欄 | ±0.1 1/m | 独自非カスタムは±0.05へ上書き。カスタム/FMEは欄の値（プロファイル適用を除く） |
| 傾斜色飽和 | 60度 | 傾斜の計算値ではなく色正規化を変更 |
| 標高色欄 | 200〜2000m | 独自非カスタムは0〜3000mへ上書き |
| 標高自動検出 | オフ・余白50m | オン時は全域の近似min/max±余白。組込み・独自非カスタムはオフへ上書き |
| FMEストレッチ | 長野県実績値 | R 65〜234、G 57〜229、B 66〜216。全国共通仕様ではない |
| XYZ | オン・PNG・12〜16 | 候補上限100000 |
| WebP選択時 | 非可逆・QUALITY 75 | 可逆は明示選択。WEBPドライバ必須 |
| 結合GeoTIFF・読込み | オン・オン | 全域画像・索引を追加 |
| 標高DEMのGeoTIFF保存 | オフ（0.12.4） | 平滑化前の単バンド標高。CS画像と別成果 |
| GeoTIFF圧縮 | DEFLATE | 可逆。納品仕様と照合 |

「画面の設定を使用」でも独自方式の従来標準・淡色・地形強調・グレースケールは各組込み値を使います。個別の数値・色を変えるには独自方式の「カスタム」を選びます。FME方式では独自方式専用の色調欄は使いません。

### 組込みプロファイル

| 選択 | セル | σ | 曲率 | 標高色 | 位置付け |
|---|---:|---|---|---|---|
| 標準CS・1m | 1m | m方式3m | ±0.1 1/m | 200〜2000m | FME組込み値。「標準」は最適性の比較結果ではない |
| 試験処理・2m | 2m | m方式3m | ±0.1 1/m | 200〜2000m | 粗い試行用 |
| 林野庁近似設定（暫定）・1m | 1m | m方式3m | ±0.03 1/m | 200〜2000m | **暫定**。認定設定・参照成果一致ではない |

いずれもFMEマニュアル方式・傾斜色60度・標高自動検出オフを適用します。傾斜法、FME配色、ストレッチは画面の選択を引き継ぎます。例：組込み1mを選ぶとセル欄が2mでも実効値は1mです。

外部JSONは画面から組み立てた設定へ読込み値を反映します。入力、入力形式、出力先、出力CRS、系番号、標高単位確認は保護対象です。`sigma_unit` のない旧JSONはm方式、`slope_algorithm` のない旧JSONは画面選択中の傾斜法を使い警告します。以前の中央差分による成果を再現する場合は中央差分を明示します。mainで`nodata_edge_mode`のない旧プロファイルを読むと標準方式へ固定され、画面で境界補完を選んでいれば警告します。実効値はログ・`run.json`で確認します。

個別ファイル指定の上限30件と、XYZ候補上限100000枚は別の制限です。XYZ候補は指定ズームごとのEPSG:3857外接範囲に含まれるタイル数の合計で、全透明タイルを省く前に判定します。上限を超える場合は入力範囲・ズームを減らします。

## 暫定推奨

| 用途 | 出発点 | 採用前の確認 |
|---|---|---|
| 初回 | 小範囲GeoTIFF・独自従来標準・入力に合うセル・Horn・σ3m・XYZオフ | 位置・欠測・谷尾根・完了状態 |
| FME資料系配色 | 1m級DEMなら標準CS・1m | 標高範囲・長野ストレッチの適否。実FME一致は未確認 |
| 処理量見積り | 小範囲・入力に無理のない粗いセル、必要なら試験処理2m | 微地形の消失・時間・容量 |
| 異なる格子の比較 | 同一CRS・範囲、m方式σを固定 | 元DEMの情報量・補間・実効σ |
| 細かい起伏 | px方式も比較候補 | ノイズ・透明域。3pxが常に適切とは限らない |
| 分割処理・追加 | 全域で同じ標高色範囲・描画・傾斜・曲率・ストレッチ | 別実行の自動検出で色基準が変わる |
| 画素値保持 | GeoTIFF・PNG・WebP可逆 | 閲覧側互換性・透明度・納品仕様 |
| Web容量削減 | 小範囲・ズーム12〜14、PNGとWebP非可逆を比較 | 視認性・容量。QUALITY 75の最適性は未検証 |

自動標高検出を独自方式で使うにはカスタムを選びます。FMEでは組込みを使わず「画面の設定を使用」で調整します。範囲を固定するには、試行の `rendering.normalization.elevation_m` を読み、自動検出をオフにして同じ上下限を入力します。

σ3mと3pxは1m格子で同じです。0.5m格子では3mと1.5m、2m格子では3mと6mです。小さいσは起伏とノイズを残します。小さい曲率飽和値は弱い起伏の色を強める一方、飽和して差を失う場合があります。

## 比較検証済みの範囲

| 証跡 | 確認するもの | 確認しないもの |
|---|---|---|
| [色・傾斜回帰試験](../csmap_sheets/tests/test_color.py) | 人工面・LUT・重み・色補正の計算 | 実地形での最適性 |
| [σ回帰試験](../csmap_sheets/tests/test_sigma_unit.py) | m/px換算・互換・格子との関係 | 判読上の最適σ |
| [公開前検査](validation/submission-preflight-0.12.3.md) | 記載環境・ZIPでの起動と回帰 | Windows全受入・FME実成果一致 |
| [監査記録](validation/project-audit-20261017.md) | 公開・開発・別PRの区分 | W3/W4実DEM比較の完了 |

FME資料±10から±0.1 1/mへの換算は[既存検証記録](../csmap_sheets/VALIDATION.txt)のFMW除数確認が根拠です。単位換算の確認と画像一致・設定の優位性を区別します。±0.03は別の暫定候補です。

## 比較の残し方

同一範囲・入力・CRS・セル・傾斜法・欠測を固定し、一度に1条件を変えます。版／コミット、OS・QGIS・GDAL・SciPy/NumPy・PDAL、DEM出典・年度・鉛直基準・格子、設定JSON、run.json、ログ、表示倍率をそろえた画像を保存します。

数値一致（RGBA差・傾斜曲率誤差）、判読（何が読みやすいか）、運用（時間・容量・仕様適合）を別評価にします。参照側の版・方式・入力・σ・欠測規則も特定します。証跡なしの設定を「比較検証済み」に昇格させません。
