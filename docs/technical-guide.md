## 処理・座標

入力発見・形式変換 → 共通平面直角座標系・正方格子への整合とモザイク → 図郭＋余白の読込み → 傾斜・平滑化曲率 → 配色 → 図郭GeoTIFF・索引 → 任意の結合画像・XYZ、の順です。

入力は[input_sources.py](../csmap_sheets/engine/input_sources.py)、系推定は[zone_inference.py](../csmap_sheets/engine/zone_inference.py)、図郭は[map_sheets.py](../csmap_sheets/engine/map_sheets.py)を参照してください。

- 出力セルサイズは再投影後の計算格子の間隔mです。入力格子・テキスト復元格子・XYZ画素と区別します。細かい補間で観測情報は増えません。
- 出力CRSは対象地区・測地系に対応する平面直角座標系。複数系をまたぐ入力は系別に処理します。
- 水平整合は鉛直基準変換ではありません。標高m・鉛直基準は利用者が確認します。測量Xは北、Yは東で、一般的なGIS X/Y順と逆です。
- 年度・地表分類・標高基準の段差は補正しません。ラスタ重複部は後に列挙されたDEMの有効値を優先します。自動の新旧判定・平均化はありません。入力順を保存します。

### 入力・出力CRSの条件

出力CRSの自動推定は「出力の平面直角座標系」が空欄の場合だけ働きます。推定できなければ停止するため、対象地区の測地系・系番号を確認して指定します。

| 入力 | 自動推定の条件 |
|---|---|
| 標高ラスタ | 先頭ファイルに日本の平面直角座標系が記録されていること。経緯度CRSやCRSのないTIFF＋TFWだけでは推定不可 |
| 国土地理院DEM | ファイル名・GMLの地域メッシュと測地系が確認でき、対象の系が一つに定まること |
| LAS/LAZ | 明示した入力CRSが平面直角座標系、または読めるヘッダーのCRS・測地系が一つにそろうこと |
| 標高テキスト・森林航空レーザ成果 | 「入力の水平座標系」に対応する平面直角座標系を明示すること。LEMの系番号だけでは測地系を確定できない |

標高ラスタの自動推定は実ファイルのCRSを使います。CRSのないラスタへ「入力の水平座標系」を指定しても、それだけで出力CRSの自動推定はできません。森林航空レーザ成果として指定したGeoTIFFも、出力の自動推定には明示的な入力CRSが必要です。必要な場合は出力CRSを直接指定します。

LEMの付属ヘッダーは、同じフォルダーにある同名のCSV/TXTメタデータです。LEM内部のレコード先頭とは別で、両方ある場合はCSVを優先します。森林航空レーザ成果では-9999・-1111を欠測として扱います。正常な0mを欠測指定しないでください。値の定義・単位は入力成果の仕様で確認します。

## 傾斜

未平滑化標高から勾配dx・dyを求めます。

```text
slope_deg = atan(sqrt(dx² + dy²)) × 180 / π
```

既定はHorn法です。3×3近傍を北西から a b c / d e f / g h i、格子間隔をcellとすると、

```text
dx = ((c + 2f + i) - (a + 2d + g)) / (8 × cell)
dy = ((g + 2h + i) - (a + 2b + c)) / (8 × cell)
```

中央差分は東西・南北各2点の差を2cellで割り、中央差分で作成した成果の再現用に選べます。配色には勾配の大きさを使います。「暗さが飽和する角度」は色正規化だけを変え、傾斜計算自体は変えません。Horn法選択だけで他ソフトの成果一致は保証できません。

## 曲率とσ

Gaussian平滑化標高sの負のラプラシアンです。

```text
C = (4s中心 - s東 - s西 - s北 - s南) / cell²
```

標高・格子がmなら単位1/m。凸型・尾根が正、凹型・谷が負です。断面曲率・平面曲率やSAGAの各曲率とは異なる指標です。

| 指定方式 | 実効σpx | 実効σm |
|---|---|---|
| m | σm / cell | σm |
| px | σpx | σpx × cell |

半径はceil(4×実効σpx)、幅は2×半径＋1。σ=0は平滑化なしです。0.5m格子のm方式3mは幅49px、px方式3pxは幅25pxです。σは色調だけでなく地形量を変えます。`run.json`の `rendering.terrain_calculation.smoothing` に指定方式・値・実効σ・カーネルを記録します。

## 欠測・外縁

支持領域は `halo = ceil(4 × 実効σpx) + 1`。平滑化と差分に必要な範囲に欠測・画像外が触れる画素を透明にします。σ3m・1m格子では13画素＝13mです。σ=0でも1画素の支持領域があります。

内部では無効標高を0に置換しますが、影響域を安全マスクで除外します。正常な0mをNoDataにしないでください。透明域を外部補間で埋めても、本処理で確認できた地形にはなりません。

上記は既定の「標準」方式（`nodata_edge_mode=safe_mask`）の規則です。mainには、明示的に選んだときだけ使う「境界補完」方式（`pss_approximation`、未リリース）があり、計算時だけ画像外を端値で延長し、欠測した近傍を対象画素の中心値で代用します。欠測している中心画素は透明のままで、補完値は標高ではありません。PSS/FME実出力との一致は未確認です。詳細は[README_ja.md](../csmap_sheets/README_ja.md)の「欠測・端部の処理方式」を参照してください。

各図郭を余白付きで計算し、中央を切り出すため、全域RAM展開を避けてブロック境界の筋を防ぎます。元DEMの段差や別実行の設定差までは解消しません。欠測・外縁規則は他実装との画素差の原因にもなります。

## 配色と設定範囲

### 独自方式 v0.4互換

曲率3色補間 → 標高色混合 → 傾斜暗さの乗算 → 彩度・コントラスト・明るさ・ガンマ補正です。従来標準は曲率±0.05 1/m、標高0〜3000m。個別色・数値を使うにはカスタムを選択します。

曲率飽和値の外はクリップします。小さい飽和値は弱い起伏へ強い色を割り当てますが、曲率計算自体を変えません。強い補正はRGBの0/255クリップを生みます。

### FMEマニュアル方式

標高・傾斜A・傾斜B・曲率A・曲率Bを0〜255のLUTへ割り当て、重み0.125・0.25・0.25・0.125・0.25で加算します。曲率Bの127・128番は中間の黄色。任意のストレッチ後、最後に整数へ丸めます。RGB表は詳細READMEを参照してください。

QGIS画面のFME初期値は標高200〜2000m、傾斜0〜60度、曲率±0.1 1/m、ストレッチは長野県実績値です。color_fme.py直接呼出しの省略ストレッチnoneとは区別します。

長野ストレッチはR 65〜234、G 57〜229、B 66〜216を0〜255へ線形変換します。全国共通仕様ではなく「なし」「カスタム」も選べます。

既存検証記録ではFMW核が `0 -1 0 / -1 4 -1 / 0 -1 0`、除数が `cell_size² × 0.01` で、資料±10が本実装±0.1 1/mに対応すると確認されています。これは単位・核の確認です。平滑化・補間・欠測条件に差があるため、**FME参照実出力との画素完全一致は未確認**です。waigania13/CSMapMaker（SAGA曲率・QGISレイヤー合成）の再現とも区別します。

林野庁近似設定（暫定）の±0.03は別の試行値です。±0.1の換算値・林野庁の認定設定ではありません。

### 標高自動範囲

再投影・モザイク後の対象全域でGDAL近似min/maxを求め、余白（既定50m）を加えます。図郭別ストレッチではありません。別々の実行では全域が違うため同じ標高の色も変わり得ます。

実効範囲は `rendering.normalization.elevation_m`。自動検出を保存したJSONは次回入力で再検出します。範囲固定の再利用とは区別します。組込み・独自非カスタムの上書きは[推奨設定](recommended-settings.md)を参照してください。

## 図郭・画像・XYZ

| レベル | 東西m | 南北m | 1mセル |
|---|---:|---:|---|
| 5000 | 4000 | 3000 | 4000×3000px |
| 2500 | 2000 | 1500 | 2000×1500px |
| 1000 | 800 | 600 | 800×600px |
| 500 | 400 | 300 | 400×300px |

レベルは寸法・番号の選択で、DEM精度・地図情報レベル認定ではありません。外周も定寸・欠測透明、全透明図郭は省略します。GeoTIFFはRGBA画像で標高ラスタではありません。TFWは左上画素中心座標です。

[XYZ処理](../csmap_sheets/engine/xyz_tiles.py)は図郭群を束ねたcs_relief.vrtをEPSG:3857へ再投影し、256px・北端y=0で出力します。タイル別の色範囲変更はありません。全透明タイルを省略し、黒を欠測扱いしません。WebP非可逆は色を変え得るのでRGBA差比較にはPNG・可逆を使います。

0.12.3以降（GitHub版0.12.4を含む）の索引QMLは表示改善で、CS計算変更ではありません。

0.12.4の `dem_merged.tif` は計算用projected_dem.vrtから保存する単バンド標高です（既定オフ）。平滑化前の値・格子・CRS・NoDataを引き継ぎ、保存時に追加補間しません。CS図郭の余白へ拡張した画像ではありません。[検証範囲](validation/merged-dem-0.12.4.md)を参照してください。

## 再現と限界

run.jsonには入力順・実効設定・配色・ライブラリ版・バックエンド・処理状態を記録します。元入力やライブラリ本体は含まれないため、入力の識別子・ハッシュ・出典、版／コミット、ログも保存します。完了は `status: completed` で確認します。

SciPyがなければ[NumPy代替フィルタ](../csmap_sheets/engine/filters.py)を使います。自動比較の曲率許容誤差・透明域一致と、演算順によるRGB差の可能性を区別します。同一案件は同一バックエンドで記録してください。

[公開前検査](validation/submission-preflight-0.12.3.md)の合格はWindows全受入・QGIS 4・実DEM判読・FME/PSS一致の証明ではありません。比較には入力・CRS・格子・傾斜法・σと単位・欠測・色範囲・参照版をそろえます。
