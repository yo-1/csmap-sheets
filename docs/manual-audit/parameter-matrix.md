## 抽出方法・読み方

- QGISをimportせず、algorithm.pyのパラメータコンストラクタの名前・型・ラベル・既定値・選択肢を静的抽出し、ループで追加する数値・色・ストレッチ項目を展開した。入力パラメータは**92項目**。Processing出力は別表。
- 表は画面定義上の初期値。QGISの履歴・ユーザー設定・プロファイル読込後の画面を再現したものではない。列挙値は0始まり。
- 最終UIラベルは定義文字列に【区分】を付加し、テキスト／森林レーザの重複接頭辞を除去する。[csmap_sheets/algorithm.py:824–836](https://github.com/yo-1/csmap-sheets/blob/12447d3f7cf8a04bb1e63d798ddc189f5976c889/csmap_sheets/algorithm.py#L824-L836)。区分と説明はラベル欄に含む。長文説明は[csmap_sheets/algorithm.py:169–208](https://github.com/yo-1/csmap-sheets/blob/12447d3f7cf8a04bb1e63d798ddc189f5976c889/csmap_sheets/algorithm.py#L169-L208)も参照。
- 「v0.5節未取得」は実在する節名ではなく、原本取得後に照合する話題の目印。正誤は[discrepancies.md](discrepancies.md)の判定規則に従う。
- 「高度」は詳細パラメータ。色はRGBで、不透明度編集なし。ファイル／CRSの未指定可否はoptionalに記録する。
