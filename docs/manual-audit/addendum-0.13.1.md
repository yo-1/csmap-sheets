# 監査追補：v0.12.3基準監査から v0.13.1 までの差分（2026-10-31）

Issue #46 の監査3文書（parameter-matrix.md / discrepancies.md / figure-capture-checklist.md）は、
実装基準 v0.12.3（`12447d3`）・手順書 Drive版v0.8 を基準に 2026-10-20 に作成された。
本追補は、その後の main（v0.13.1、`24a061f`、PR #59 マージ時点）までの差分のうち、
手順書と監査に影響するものを静的照合で整理する。計算コード・既定値は変更しない。
Windows/QGIS 実機の確認は含まない（実機分は §4 に分離）。

## 1. パラメータ差分（algorithm.py の静的抽出比較）

基準版と現行 main のパラメータコンストラクタを名前で比較した。

- 追加：`MERGED_DEM`（0.12.4、マージ済み標高DEMの任意保存。既定オフ）
- 追加：`NODATA_EDGE_MODE`（0.13.0、欠測・ラスター端部の処理方式。既定は標準 `safe_mask`）
- 削除：なし
- ループ生成される数値・色・ストレッチ系項目の構造に変更はない（監査時の92項目表の骨格は維持され、上記2項目が増える）

## 2. 挙動・出力の差分（手順書への反映が必要なもの）

| 版 | 変更 | 手順書・監査への影響 |
|---|---|---|
| 0.12.4 | 出力 `DEM_MERGED_GEOTIFF` と run.json の `dem_merged_geotiff` を追加 | 成果物一覧と run.json 説明へ追記が必要 |
| 0.13.0 | 設定プロファイル形式が v5（`csmap-settings-profile-v5`）へ。方式キーのない旧プロファイルは標準方式として読み、画面選択と異なる場合は警告して `profile_warnings` に記録 | プロファイル互換の説明を v5 前提へ更新 |
| 0.13.0 | 入力形式の選び間違い案内（選んだ形式のファイルが0件で停止する場合、別形式の候補件数と選び直し先を提示。設定は自動で切り替えない） | エラー時の案内として手順書へ記載できる（Issue #71 の対象画面でもある） |
| 0.13.1 | 欠測マスク後に有効画素がなくなる図郭をスキップして継続。run.json に `sheets.skipped` / `sheets.partial_success` を追加。全図郭無効は failed | 成果物・run.json・警告の説明へ追記が必要（PR #74 の付録Fには版差として記載済み） |
| 未リリース（PR #57） | 外部プロファイルが処理上限を既定より大きく設定した場合、画面と run.json の `profile_warnings` へ警告（値は拒否しない） | 次版で採用決定済み。実機での警告表示確認が次版受入の項目 |

## 5. 実機セッションでまとめて行う項目（v0.13.1 / 次版受入）

2. 設定画面の撮影（上・中・下部）：`NODATA_EDGE_MODE`（欠測・端部の処理方式）と `MERGED_DEM` の表示を含む現行版の画面一式（旧版原本11点の差し替え分を含む）

4. 空図郭スキップ時の警告表示と、結果に出る `sheets.skipped` の画面・ログ側の見え方
5. 図郭索引の枠線のみ表示（0.13.0 の読込時スタイル戻し）の目視確認
