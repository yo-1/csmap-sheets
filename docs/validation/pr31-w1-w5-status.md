## W1 の内訳

根拠：`windows-0.13.0.md`（QGIS 3.44.13、2026-10-22）、
`ui-fixes-0.12.3.md`、`manual-audit` 3文書。

- 保存ダイアログ・JSON保存：保存成功のログで確認済み（JSON本体は未取得）。
- JSON再読込：外部JSONを指定して再実行し、4図郭・completed を確認済み。
  全設定のフィールド単位比較は未実施。
- 図郭QML：初版の塗りつぶしを、修正版で枠線のみになることを画面で確認済み。
- GeoTIFF案内：0.12.3 監査と画面記録の範囲で確認済み。
- DPI・表示幅：`ui-fixes-0.12.3.md` が実機未確認と明記。以後の記録にもない。
- ZIP再導入：0.13.0 の記録では実機導入ZIPの SHA が未取得だった。その後、
  v0.13.1 配布ZIPと Windows 検証用テストZIPのコードが、VERSION 文字列と
  metadata・文書類を除きバイト一致であることを 2026-10-31 に直接比較で
  確認した（監査追補 PR #75）。ただし「配布ZIPそのものからの導入」は
  未実施で、実機セッションの最小項目として残す。

## W2 の内訳

- 旧プロファイル（方式キーなし）の safe_mask 固定・警告・`profile_warnings`：
  実装と自動テストは存在する（現行スイートでも合格範囲）。Windows 実機では
  未確認（`windows-0.13.0.md` の明記どおり）。
- 境界補完（pss_approximation）のJSON保存・再読込の往復：実機未確認。
  標準方式の往復のみ実施済み。
- 実DEMの透明欠測中心：人工DEMでは欠測穴中心の透明をログ・画面で確認済み。
  実DEMについては、TIFF 2件の既往差分（alpha=0、RGBA最大差1、差分1,345画素）
  が run.json を欠くため、同条件の再現合格とはしない（統括指示 2026-10-24）。

## W3・W4 について

- W3 は論文トラックの比較であり、リリース受入の合否とは分ける。
  論文側の現況（`docs/coordination/20261024_research-to-gpt_csmap_comparison_status.md`）
  でも、原データに基づく統計と完全照合は未実施とされている。判定には
  論文担当の既存成果（条件・版・出力）の照合が先で、重複計算はしない。
- W4 の参照照合は、監査の M20/T20 と同じく未検証のまま据え置く。
  人工DEMでの自己一致（81ラスタ差0など）は独立参照との一致ではない。
  広域負荷は、2026-10-28 の Windows 全件実行（神奈川 merge DEM、
  候補1,392図郭、completed、1,103出力/289スキップ）が完走の証跡になるが、
  所要時間・メモリの定量記録はその報告に含まれていない。
