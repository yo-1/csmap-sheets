## 変更範囲

- `algorithm.py`: JSON保存欄の専用ウィジェット指定、実行時の拡張子補完、GeoTIFFと出力格子の案内。
- `profile_widget.py` / `profile_paths.py`: 最終保存名の決定と画面の上書き確認。`.JSON`も保持。
- `engine/output_style.py`: 塗りなし・0.2mmの実線枠のQML。図郭の両出力経路で隣接ファイルとして保存。
- `README_ja.md`、版番号、変更履歴、回帰試験、QGIS試験起動スクリプト。

保存欄は、標準の出力先ウィジェットがカスタムウィジェット指定を使用しないため、任意の文字列パラメーターと専用ウィジェットで構成する。`SAVE_PROFILE`キーとJSON形式は維持。Pythonから渡す保存先も拡張子を補完する。非対話のProcessing実行では呼出側が上書きを管理し、GUIの確認を出さない。

QMLはGPKGと同じフォルダーに置く。既存プロジェクトの保存済みスタイルは変更しない。移動するときは両方を移す。

## Windows / QGIS 3.44 確認手順（未確認）

1. ZIPを「プラグインの管理とインストール」→「ZIPからインストール」で導入し、QGISを再起動。画面・ログの版が0.12.3であることを確認。
2. 小さいGeoTIFFを指定し、保存先に拡張子なしの名前を指定して実行。`.json`が作られることを確認。`.json` / `.JSON`も試し、二重付与されないことを確認。
3. 同じ名前のJSONがある場所で、拡張子を省略して保存先を選ぶ。上書き確認に`.json`付きの最終パスが出ること、「いいえ」・保存ダイアログ取消で既存ファイルが変わらないこと、「はい」で保存できることを確認。保存欄の直接入力でも同様に確認。
4. 保存したJSONを「外部JSONプロファイル」で読み込み再実行。傾斜法・平滑化・配色などが復元され、現在指定した入力・出力・座標系が維持されることを確認。
5. 処理完了後の図郭が枠線だけで下のCS画像を隠さないことを確認。レイヤーを外し、新しいプロジェクトでGPKGを手動追加しても同じ表示であることを確認（同じフォルダーにQMLを置く）。
6. GeoTIFFについて入力セル間隔の自動取得・テキスト格子間隔不要・出力格子との違いが説明欄と項目名に表示されることを確認。

Windowsのネイティブ保存ダイアログ、表示幅・DPI、プラグイン再導入は実機未確認。LinuxでのQGIS API試験の合格とは区別する。
