## 残る確認の短い手順

1. 最終ZIPのSHA-256を照合し、ZIPから上書き導入後QGISを再起動。版0.13.0と「境界補完」を確認する。
2. 必要に応じ、旧JSON移行、境界補完のJSON往復、入力誤選択案内、日本語パスを小範囲で確認する。
3. XYZの表示を確認する場合は生成タイルを開き、透過と内容を確認。広域性能や測量精度の試験には拡張しない。
